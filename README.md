# Programming techniques and algorithms

This project was created as part of a seminar activity for the **Programming Techniques and Algorithms** course.

##  Project Description

The application allows the user to manage a list of products stored in a binary file.

Each product contains:
- Product code
- Product name
- Brand
- Price
- Stock

The application has a menu with several options for managing the products.

##  Features

The program allows the user to:

 - Create a new product file
 - Add new products
 - Modify the stock of a product
 - Reduce the price of a product based on its stock
 - Delete a product
 - List all products
 - List products with low stock
 - Display a product by its code
9. Exit the application

##  Concepts Used

- Functions
- Binary files
- Text files
- File operations (`fopen`, `fread`, `fwrite`, `fseek`, `rewind`)
- Reading and writing data
- Searching for products
- Updating and deleting records
- Basic control structures (`if`, `while`, `switch`)

## Files

- `gestiune_magazin_electronice.c` - main C source code
- `magazin.dat` - binary file containing product data
- `report.txt` - example text report
- `stoc_redus.txt` - example report for products with low stock
- `Documentatie.docx` - project documentation
